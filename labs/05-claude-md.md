# Lab 5 · CLAUDE.md (15 min)

1. Open the repo's `CLAUDE.md` (and `~/.claude/CLAUDE.md` if you have one).
2. For each line ask: *"Would Claude get this wrong without it?"* Mark the ones that fail the test.
3. Think back to labs 2–4: find **one** mistake Claude made that a single line in `CLAUDE.md` would have prevented.
4. Write that line. For personal preferences use `CLAUDE.local.md` instead (kept out of git by the exclude from lab 0).
5. Start a fresh session (`/clear`) and check that the new line changes the behaviour.

Don't push changes to the team's `CLAUDE.md` during the course; propose them afterwards.

**Done when:** you have one line that fixed a real mistake, and a list of lines you would delete.
